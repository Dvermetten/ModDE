## Core objects

`modde.Settings`, `modde.Modules`, the option enums (`modde.MutationBase`, ...)
and the low-level optimizer `modde._core.ModularDE` come from the compiled
extension. Their full signatures are in the type stub `modde/_core.pyi` that is
installed with the package, so they show up in your editor.
